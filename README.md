# PARTO HEKARI BASIC SCHOOL 🏫
قوتابخانا پارتۆ هەکاری یا بنەڕەت

A futuristic, high-performance web utility application designed for **Parto Hekari Basic School** (Established 2006), featuring integrated Math and Grade calculators with a unique Cyber-Glassmorphism UI.

## ✨ Features (تایبەتمەندی)
- **Cyber-Glassmorphism UI:** Modern, responsive design with particle animations and dark cyber aesthetics.
- **Math Calculator (حاسیبا بیرکاریێ):** Built-in scientific calculator for quick math solving.
- **Grade Calculator (حاسیبەی نمران):** Dynamic student grade average and pass/fail status tracker.
- **School Overview:** Detailed profile of Parto Hekari Basic School (Est. 2006).

## 🛠️ Technologies Used
- HTML5 / CSS3 / JavaScript (Vanilla)
- Tailwind CSS (via CDN)
- FontAwesome & Google Fonts (Noto Naskh Arabic)
